# PhotoCraft

Нативный редактор изображений на Rust для художников. Этот независимый форк
[PhotoCraft](https://github.com/storytold/photocraft) сосредоточен на Linux и Wayland:
цифровой живописи, работе с графическими планшетами и привычном для пользователей
Photoshop редактировании слоёв, масок и PSD.

Проект находится в ранней альфе. Цель — свободная альтернатива Photoshop для
художественной работы на Linux; до полноценной замены в профессиональных задачах
ещё предстоит много работы.

## Направление форка

- **Linux и Wayland:** работа в нативной сессии, масштабирование интерфейса,
  ввод и взаимодействие с рабочим столом.
- **Инструменты художника:** кисти, отзывчивый холст, нажим и наклон пера,
  удобная работа со слоями и выделениями.
- **Совместимость:** сохранение редактируемых документов, обмен PSD и работа
  с разной глубиной цвета.
- **Надёжность:** сохранность работы и предсказуемое поведение важнее количества пунктов меню.

Это приоритеты разработки, а не список уже завершённых возможностей.
В частности, поддержка пера через Wayland `tablet-v2` пока не реализована;
существующая поддержка планшетов на Linux использует X11/XInput2.
Текущее состояние движка описано в [дорожной карте](docs/roadmap.md) и
[таблице проверок](docs/scorecard.md).

## Что есть в основе

- Слои, маски, режимы наложения, корректирующие слои и эффекты.
- Кисти, выделения, трансформации, текст и векторные формы.
- Чтение и запись PSD, собственный формат `.pcraft` и экспорт изображений.
- Нативный интерфейс egui/eframe с рендерингом через wgpu.
- Общий Rust-движок для приложения, CLI и автоматизации через MCP.

Совместимость с Photoshop остаётся неполной. Наличие команды в меню само по себе
не гарантирует совпадения поведения или точного воспроизведения файла.

## Сборка на Linux

Нужен Rust stable 1.95 или новее. Для Debian/Ubuntu установите системные зависимости:

```sh
sudo apt install build-essential pkg-config libxkbcommon-dev libwayland-dev \
  libx11-dev libxrandr-dev libxi-dev libgl1-mesa-dev libgtk-3-dev
```

Из каталога этого репозитория:

```sh
cargo run --release -p photocraft
```

Открыть документ при запуске:

```sh
cargo run --release -p photocraft -- path/to/image.psd
```

Запускайте приложение из своей Wayland-сессии для проверки работы в этом окружении.
Другие платформы и веб-сборка унаследованы от исходного проекта; основной фокус
этого форка — Linux. Подробности сборки, дополнительных шрифтов и диагностики:
[руководство разработчика](docs/development.md).

## Происхождение и лицензия

Форк основан на [исходном PhotoCraft](https://github.com/storytold/photocraft).

рекламные ссылки исходного бренда удалены; собственный логотип пока не добавлен.

Код распространяется на условиях [MIT](LICENSE-MIT) или

правах сохранены в [NOTICE](NOTICE) и файлах лицензий.
